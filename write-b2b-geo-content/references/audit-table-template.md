# 内容检查表

正文完成后检查以下重要内容。检查表作为内部审核材料单独保存。

|检查项|检查结果|审核依据或发现的问题|处理方式|
|---|---|---|---|
|Prompt回答|通过 / 待调整|核心问题和子问题是否完整回应||
|独立证据块|通过 / 待调整|主要板块能否独立理解，结论与证据是否完整||
|客户事实|通过 / 待调整|产品功能、参数、案例和数据是否与客户资料一致||
|产品承接|通过 / 待调整|承接位置是否自然，适用条件与能力边界是否清楚||
|资料完整性|通过 / 待调整|与本篇相关的重要资料是否存在遗漏或冲突||
|标题与H2|通过 / 待调整|标题是否符合文章类型，多数H2是否回应用户问题||
|竞品呈现|通过 / 待调整 / 不适用|是否按统一维度集中比较并突出客户差异化||
|引用对应|通过 / 待调整|正文编号与参考资料是否一一对应||

检查结果为“待调整”时，先完成修订，再向用户提交正文。
