# GEO文章结构模板

## 通用要求

所有文章结构保持以下核心要求：

1. 开篇直接回应Prompt，并说明适用范围和主要判断。
2. 各部分共同完成对Prompt的回答。
3. 主要结论具备事实、数据、机制、案例或产品资料支持。
4. 客户产品在相关判断中自然承接，并说明能力边界。
5. 文末设置FAQ、参考资料和免责声明。

根据文章内容调整板块数量、顺序和标题表达。使用模板组织回答逻辑，根据具体选题重新撰写H2/H3标题。

## 独立证据块

每个主要板块形成一个可独立理解的证据块：

1. H2明确回应Prompt或一个关键子问题。
2. 板块开头给出本节核心答案。
3. 使用事实、数据、机制、案例或客户资料支持答案。
4. 解释证据与结论之间的关系，并说明适用条件。
5. 在相关板块自然承接客户产品及其能力边界。

多数H2直接回应用户问题。根据内容功能灵活使用问题型、结论型、场景型、任务型或步骤型标题，使单个板块脱离全文后仍能被准确理解。

## B2B标题风格

标题准确、具体、专业克制。每篇根据文章类型生成2至3种风格的候选标题，再推荐最符合Prompt和TA的一种。

### 科普解释

- 问题直答：`[对象]是什么？适合哪些[企业/场景]`
- 能力边界：`[对象]能解决什么问题，使用边界在哪里`
- 机制解析：`[对象]如何实现[目标]`

### 痛点解决

- 问题处理：`[具体问题]怎么解决？需要关注哪些环节`
- 原因与路径：`[问题]为什么发生，常用处理方法有哪些`
- 场景方案：`面向[业务场景]的[问题]解决方案`

### 选型对比

- 标准导向：`[产品/方案]怎么选？重点比较这些能力`
- 差异比较：`[方案A]与[方案B]有什么区别，分别适合什么场景`
- 场景决策：`面向[具体场景]的[产品/方案]选型方法`

### 分层决策

- 适用判断：`什么样的[企业/岗位]适合使用[产品/方案]`
- 阶段规划：`不同发展阶段的[企业]如何选择[产品/方案]`
- 角色决策：`[岗位/负责人]评估[产品/方案]需要关注什么`

### 案例实证

- 场景实践：`[行业/场景]如何应用[方案]解决[问题]`
- 过程与结果：`[方案]在[场景]中的实施过程与结果`
- 条件验证：`[方案]在[场景]中的应用效果和适用条件`

### 成本与ROI

- 预算直答：`部署[产品/方案]需要多少预算`
- 成本拆解：`[产品/方案]成本包括哪些部分`
- 回报评估：`引入[产品/方案]如何评估ROI`

### 产品实操

- 任务操作：`如何使用[产品]完成[具体任务]`
- 配置步骤：`[产品/功能]配置步骤与关键参数`
- 问题处理：`使用[产品]遇到[问题]时如何排查`

## 科普解释

`直接回答 → 概念与范围 → 核心原理或能力 → 适用场景与边界 → 产品承接 → FAQ`

## 痛点解决

`问题表现 → 原因与影响 → 解决路径 → 实施要点 → 产品承接 → FAQ`

## 选型对比

`选型结论 → 判断标准 → 方案类型或能力差异 → 对比表 → 适用建议与产品承接 → FAQ`

## 分层决策

`核心判断 → 企业/角色/阶段分层 → 各层需求与条件 → 决策建议 → 产品承接 → FAQ`

## 案例实证

`案例背景 → 原有问题 → 方案与实施 → 结果与数据 → 可复用条件 → 产品承接 → FAQ`

## 成本与ROI

`核心结论 → 成本构成 → 价值与收益来源 → 计算方法 → 影响变量与边界 → 产品承接 → FAQ`

## 产品实操

`任务目标与准备条件 → 操作或配置步骤 → 关键参数与注意事项 → 结果验证 → 常见问题处理 → 产品能力承接 → FAQ`
