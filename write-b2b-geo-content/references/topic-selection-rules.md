# GEO选题判断规则

## Query Fan-out

使用Query Fan-out拆解原始Prompt并扩展问题空间。根据Prompt实际需要，从概念、场景、判断标准、方案差异、实施条件、成本回报、风险和验证等维度生成5至8个子问题。

Query Fan-out属于问题拆解结果。用项目数据、搜索结果、AI回答和客户资料验证其选题价值。

## 选题证据

按照以下顺序调用证据：

1. GEO监测数据、Prompt Library和历史AI回答。
2. 内容策略、已规划选题和已发布内容。
3. 原始Prompt及3至5个高相关Fan-out查询的当前搜索与AI回答。
4. 客户产品事实、解决方案、案例和可公开数据。

轻量检索最多保留15个去重后的有效结果。记录：

- 至少在3个独立结果中重复出现的回答维度。
- GEO监测或AI回答中反复出现的判断。
- 目标TA需要且当前内容覆盖不足的问题。
- 与客户已有内容高度重合的方向。
- 客户资料能够提供独特事实、案例或判断的方向。

每个候选方向至少使用两类证据。具体写明数据结果、资料名称、重复出现的回答维度或内容缺口。

## 文章类型

|文章类型|适用Prompt|
|---|---|
|科普解释|是什么、有哪些、能否实现、原理是什么|
|痛点解决|怎么解决、如何处理、为什么出现|
|选型对比|哪个更好、如何选择、有什么区别|
|分层决策|什么企业、岗位、行业或阶段适合|
|案例实证|效果如何、有哪些应用、如何落地|
|成本与ROI|多少钱、成本怎么构成、ROI如何评估|
|产品实操|怎么使用、如何配置、如何操作、结果如何验证|

每篇确定一种主要类型。Prompt同时包含两类任务时，可以记录一种辅助类型，正文仍围绕主要类型组织。

## 候选选题评分

生成3个具有明确差异的候选方向，每项按0至2分评分：

|标准|0分|1分|2分|
|---|---|---|---|
|Prompt匹配|偏离核心问题|覆盖部分问题|完整回应核心问题|
|TA与阶段|与当前决策无关|部分相关|直接服务当前决策|
|内容缺口|与已有内容重复|存在局部差异|补充明确缺口|
|证据条件|当前资料不足|资料部分可用|客户与外部证据充分|
|产品承接|关联较弱|可以承接|能够自然形成产品认知|

推荐总分最高的方向。分数相同时，优先选择内容缺口更明确、证据条件更充分的方向。

## 竞品呈现

优先比较方案类型、能力路径和选型标准。Prompt确需品牌盘点、竞争格局或竞品横评时：

1. 将竞品信息放入统一对比表或综合比较段落。
2. 围绕与Prompt相关且能体现客户差异化的维度展开。
3. 对各比较对象使用一致的指标、时间范围和事实口径。
4. 使用简洁、可核验的竞品事实支撑比较结论。
5. 将完整证据链用于解释选型标准、客户能力和适用边界。
