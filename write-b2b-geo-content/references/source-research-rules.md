# 来源搜索与引用规则

## 搜索时点

选题确认后、大纲生成前开始搜索。先明确主要结论需要什么证据，再定向查找对应来源。

## 外部第三方来源

正文默认使用1至3个外部第三方中立来源。文章包含多个独立专业论点、跨领域判断或高风险结论时，根据证据需要增加来源。

根据论点选择最直接的来源：

|论点类型|优先来源|
|---|---|
|法规、政策与合规|监管机构、司法机关、正式法规文件|
|技术原理、方法与性能|标准组织、同行评议论文、高校、专业研究机构|
|行业规模、趋势与统计|原始统计发布方、行业协会、中立研究机构|
|安全、质量与认证|认证机构、检测机构、标准组织|
|市场和企业信息|行业协会、中立研究机构、监管或交易所公开信息|

优先使用原始、直接、中立、较新且适用范围清楚的来源。数据保留时间、样本、范围和统计口径；历史资料明确标注年份。

## 客户来源

使用客户官网、正式产品手册、技术文档、公开案例和客户数据支持产品功能、参数、方案、案例与应用结果。

- 在参考资料中标注“客户官网”“客户产品资料”或具体资料名称。
- 提供可访问的官网直接链接；内部资料记录文件名、版本或日期。
- 使用客户资料支持其明确披露的产品事实和第一方数据。
- 使用第三方中立来源支持行业领先、市场排名和广泛比较结论。

客户来源单独记录，不计入外部第三方中立来源数量。

其他企业的官网、财报和产品资料可用于核对其公开事实，单独标注为企业第一方来源，不计入外部第三方中立来源数量。

## 来源筛选

每个来源确认：

1. 与Prompt和具体论点直接相关。
2. 发布主体与原始页面明确。
3. 数据的时间、范围和口径清楚。
4. 支持范围与文章结论强度一致。
5. 链接或资料名称可供审核人员复核。

## 引用安排

- 将来源安排在其支持的句子或段落附近。
- 使用直接页面、报告或文件链接。
- 以准确转述为主，保留必要的数据、条件和边界。
- 在文末设置“参考资料”，置于免责声明之前。
- 对证据暂不充分的结论调整范围、强度或表述方式。
